# Testabdeckung P0/P1

Dieses Dokument ordnet MA-001 bis MA-022 und AC01 bis AC24 den Tests zu, die das Verhalten beobachten. Die Zuordnung Anforderung → Aufgabe → AC im Spezifikationspaket bleibt in `memory-atlas-specc/docs/TRACEABILITY.md`. AC25–AC30 und MA-023–MA-028 liegen außerhalb von P0/P1 und stehen hier nicht als offene P0/P1-Lücken.

`nicht abgedeckt` bedeutet: kein Test beobachtet diesen Teil. Dafür wurde kein Platzhaltertest ergänzt. Ein Unit-Test ersetzt keine fehlende Browser-, Windows- oder Realsample-Prüfung.
